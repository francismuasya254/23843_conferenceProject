# Student Technology and Innovation Conference - Registration System

HTML, CSS, JavaScript and PHP project (Web Application Development II, CAT 1).

## Run locally
1. Copy this folder into XAMPP `htdocs` (or WAMP `www`).
2. Start Apache.
3. Open http://localhost/23843_ConferenceProject/index.html

## Fees
Registration 1,000 + days x 500 + workshop 750 + lunch days x 300.
Individual requirement (digit 3): Year 4 (final-year) students get 5% off the subtotal.
